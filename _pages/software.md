## [CorrSurvGSD](https://github.com/xingjian-ma/CorrSurvGSD): R package for Correlated PFS and OS Group Sequential Designs

`CorrSurvGSD` evaluates correlated progression-free survival (PFS) and overall survival (OS) group sequential designs under the Fleischer model. It calculates calendar cutoffs, per-subject moments, joint correlation matrices, group-sequential boundaries, theoretical power, and optional Monte Carlo summaries.

The package also supports endpoint-specific alpha spending, futility boundaries, configurable PFS/OS gatekeeping, and a Shiny application for interactive trial-design evaluation.

## [rerand](https://github.com/xingjian-ma/rerand): R package for Rerandomization

`rerand` is an R package that provides functions for designing and analyzing experiments using rerandomization 
methodologies. It incorporates recent theoretical advances and offers user-friendly functionalities for researchers and 
practitioners.
